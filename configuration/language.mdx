---
title: "Change TecniLauncher's Interface Language"
description: "Switch TecniLauncher's UI between Spanish, English, and Brazilian Portuguese — the change takes effect immediately from the Settings panel."
---

TecniLauncher's interface is available in three languages: Spanish (default), English, and Brazilian Portuguese. You can change the language at any time from the **Settings** panel — the change takes effect immediately without restarting the launcher.

## Supported languages

| Language | Code | Notes |
|---|---|---|
| Spanish | `es-ES` | Default language |
| English | `en-US` | Full translation |
| Brazilian Portuguese | `pt-BR` | Full translation |

## Changing the language

<Steps>
  <Step title="Open Settings">
    Click the **Settings** (gear icon) in TecniLauncher's sidebar or top bar.
  </Step>
  <Step title="Find the Language selector">
    Locate the **Language** option in the settings list.
  </Step>
  <Step title="Choose your preferred language">
    Select your language from the dropdown menu.
  </Step>
  <Step title="The interface updates immediately">
    The launcher switches languages right away — no restart required.
  </Step>
</Steps>

<Note>
The language setting is saved to `config.json` as the `IdiomaActual` field and persists across launcher restarts.
</Note>

<Note>
Game language — Minecraft's in-game language — is controlled by Minecraft itself, not by TecniLauncher. Change it from Minecraft's own **Language** settings menu.
</Note>
