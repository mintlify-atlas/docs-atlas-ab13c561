TecniLauncher is a free, open-source Minecraft launcher for Windows. It's built for players who want a clean, modern alternative to the official launcher — with support for Microsoft accounts and offline play, one-click mod installation from Modrinth, and profiles for Vanilla, Forge, Fabric, and NeoForge. Whether you're a casual player or running a heavily modded setup, TecniLauncher handles downloads, Java, and updates so you don't have to.

## System requirements

TecniLauncher runs on Windows and requires no manual Java installation — the launcher manages Java automatically for each Minecraft version.

| Requirement | Minimum | Recommended |
|---|---|---|
| **Operating system** | Windows 10 (64-bit) | Windows 11 |
| **Runtime** | .NET 10 (bundled with installer) | — |
| **RAM** | 4 GB | 8 GB or more |
| **Disk space** | 200 MB for launcher + ~1 GB per Minecraft instance | SSD recommended |
| **Internet** | Required for downloading game files and authentication | Broadband |

<Note>
  Java is not required separately. TecniLauncher downloads and manages the correct Java version for each Minecraft release automatically.
</Note>
